# 🚀 Chase the Arena

**Chase the Arena** is a fast-paced, 60FPS cyber-arcade roguelite space shooter built as a single, self-contained HTML5 web application. Take command of custom strike craft, dodge blazing space hazards, collect power-ups, and conquer 10 progressive space levels all the way to the **Level 10 Solar Dragon Emperor Boss**!

## 🌟 Key Features

* **10 Progressive Space Levels**: Progress from calm meteor belts and ice comets to the **Level 10 Extreme Solar Dragon Boss**, featuring multi-phase attacks, minion summons, and an enrage mode.
* **3 Distinct Space Rockets**: Choose between the balanced **Star Falcon**, the piercing stealth fighter **Cosmic Comet**, or the heavily armored dreadnought **Galaxy Cruiser**.
* **Roguelite Power-Ups & Shop**: Collect star gems to trigger safe power-up card drafts, and spend earned coins on permanent hangar upgrades like extra armor and turbo thrusters.
* **Interactive Sandbox & AI Pilot**: Toggle **Auto-Pilot** on to watch an autonomous bot fight waves, or use the **Boosts & Speed** menu to tweak slow-motion time scale and fireball speeds.
* **Fully Responsive & Zero-Dependency**: Runs smoothly in any modern browser with procedural Web Audio sound effects and zero external asset requirements.

## 💻 Local Installation

Because the entire game is self-contained in a single file, running it locally takes seconds:

1. Clone or download this repository.
2. Rename the main game file to `index.html`.
3. Open `index.html` in any modern web browser!
